## 三、核心结论

**行业标配（≥3 家具备，闭源托管商亦然）**：生命周期管理、控制台+命令下发、文件管理、手动+定时备份、一键部署模板、版本更新、开放 API。

**普遍缺失（自研机会点）**：
1. **Mod 市场一键安装** —— 仅 Aternos/Falix 等托管平台具备，**开源面板全部缺席**（Ptero/Pelican 靠社区 egg 变通）
2. **世界级快照回档** —— 云厂商只有磁盘级快照（慢、粗粒度），开源面板的备份是全量目录（大、慢），"只回滚游戏存档"的轻量快照是空白
3. 监控告警曲线 + Webhook 通知 —— Pelican 独有

**云厂商专属（不适合自研复刻）**：弹性伸缩、多地域调度、DDoS 清洗、动态计费。

## 四、游戏方舟的功能取舍

| 决策 | 依据 |
|---|---|
| ✅ 做：容器隔离+资源配额 | 行业标配（5/9 家），Docker 天然支持 |
| ✅ 做：控制台+命令、文件管理、备份/定时/保留策略、cron 任务、一键模板、版本切换、开放 API | 行业标配 |
| ✅ 重点做：**Modrinth 市场一键装** | 开源面板空白，Modrinth API 公开免费 |
| ✅ 重点做：**世界级快照回档** | 全行业空白（备份=全量兜底，快照=存档秒回档，双轨并行） |
| ⚪ 暂缓：多用户/多节点 | 单机自用与小型社区场景优先，Roadmap 保留 |
| ❌ 不做：弹性伸缩/计费/DDoS | 云厂商专属基础设施能力 |
